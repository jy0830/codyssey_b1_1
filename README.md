# 이준엽 포트폴리오

순수 HTML / CSS / JavaScript로 만든 반응형 포트폴리오 웹사이트.

## 사용 기술
- HTML (시맨틱 마크업)
- CSS (Flexbox, Grid, CSS 변수, 반응형)
- JavaScript (DOM, 이벤트, async/await, GitHub API)

## 주요 기능
- 반응형 레이아웃 (모바일 퍼스트, 768px / 1024px)
- 다크 모드 토글 + 로컬스토리지 유지
- 햄버거 메뉴, 부드러운 스크롤
- 스크롤 애니메이션 (Intersection Observer)
- Contact 폼 유효성 검사
- GitHub API 연동 (로딩/성공/에러/빈 상태 처리)

## 기준값
- 스크롤 탑 버튼: 300px 이상
- 네비 배경 변경: 60px 이상
- Intersection Observer threshold: 0.2
